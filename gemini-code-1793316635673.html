2. REST API Endpoints Specifications

  • GET /api/usuarios - Fetch all authorized team accounts.
  • POST /api/archivos/upload - Multipart upload for technical documentation.
  • GET /api/sistemas - Returns structured tree of car subsystems and component specs.
  • PUT /api/inventario/:id - Inline updating of current stock levels.

3. Backend Integration Options

Option A (Node.js/Express Server): Deploy Express App connecting to SQLite or PostgreSQL. Bind endpoints to local storage handlers.

Option B (Google Sheets API Integration): Connect Google Apps Script webhook listening for POST/GET payload to map rows dynamically.
